Deck Matchup Win Rates
Paste match results to calculate win/loss % against different deck types.
Format — one match per line, tab or 2+ spaces between fields:

L Goat Control Warrior
First field = W or L  ·  Second = your deck type  ·  Third = opponent deck type.
Or paste directly from a spreadsheet with columns: Result | My Deck | Opp Deck

Based on nedhmn/gfwl-data deck_model_demo.
The classifier identifies Goat Format deck types by key card signatures:
Chaos Control · Goat Control · Warrior · Chaos Turbo · Chaos Return · Earth Aggro · Gravekeeper · Hand Destruction · Chaos Recruiter · Other
